# מערכת ניהול תרומות - שרת SQLite ייעודי (גרסה 2)

## התקנה ב-Render (או Railway)
1. חבר את הריפו הזה כ-Web Service
2. Build Command: `npm install`
3. Start Command: `npm start`
4. הגדר משתני סביבה (Environment Variables):
   - `ADMIN_PIN` = הקוד הסודי שלך לאתר הניהול
   - `TELEFONIM_SPREADSHEET_ID` = מזהה הגיליון (החלק שבין `/d/` ל-`/edit` בכתובת ה-URL)
   - `TELEFONIM_SHEET_NAME` = שם הטאב (ברירת מחדל: "טלפנים")
   - `GOOGLE_SERVICE_ACCOUNT_KEY_PATH` = הנתיב לקובץ מפתח חשבון השירות (ראה למטה)

## ייבוא נתונים קיימים מגוגל שיטס
1. ייצא את הטאבים "תורמים" ו"מתרימים" כ-CSV מגוגל שיטס
2. שים אותם בתיקיית השרת בשם `donors.csv` ו-`collectors.csv`
3. הרץ: `node import-csv.js`

## הקמת "חשבון שירות" בגוגל קלאוד (חד-פעמי) - בשביל סנכרון "טלפנים"
זה מה שנותן לשרת שלך הרשאה לכתוב לגיליון "טלפנים" באופן אוטומטי.

1. גלוש ל-[console.cloud.google.com](https://console.cloud.google.com)
2. צור פרויקט חדש (או השתמש בקיים)
3. בתפריט החיפוש למעלה, חפש "Google Sheets API" ולחץ **Enable** (הפעל)
4. בתפריט הצד: IAM & Admin → Service Accounts → **Create Service Account**
5. תן שם (למשל `trumot-sync`), לחץ Create and Continue, ואז Done (אין צורך בהרשאות נוספות בשלב זה)
6. לחץ על חשבון השירות שנוצר → לשונית "Keys" → **Add Key** → **Create new key** → **JSON**
7. יורד אוטומטית קובץ JSON למחשב שלך - **זה קובץ סודי, אל תשתף אותו עם אף אחד**
8. **שתף את הגיליון עצמו** (זה שבו יש את הטאב "טלפנים") עם כתובת האימייל של חשבון השירות
   (משהו כמו `trumot-sync@your-project.iam.gserviceaccount.com`, מופיע בדף ה-Service Account) - בהרשאת **עורך**
9. העלה את קובץ ה-JSON לשרת שלך (ב-Render: אפשר להוסיף אותו כ-"Secret File"), ותן ל-`GOOGLE_SERVICE_ACCOUNT_KEY_PATH` להצביע לנתיב שלו

## עמודים
- `/admin.html` - ניהול תורמים, מתרימים, סגירת מגבית, סנכרון ידני
- `/yemot` - קצה API לימות המשיח (לשים ב-ext.ini כ-`api_link`)

## מה נשאר בגיליון בדיוק כמו היום
- כל השדות הידניים בטאב "טלפנים" (A-V) - לא נוגעים בהם בכלל
- רק עמודות K-P מתעדכנות אוטומטית כל 5 דקות מהשרת החדש

## הבדל מרכזי מהגרסה הקודמת (Google Sheets)
- כל נתוני התורמים/מתרימים/מגביות בקובץ SQLite מקומי (`trumot.db`) - מהיר מאוד, בלי מכסות יומיות
- אותה בדיוק לוגיקת תפריטים לימות כמו קודם (כולל כל התיקונים: קוד תורם מתחדש לפי בניין, כוכבית בכל שלב, הקראה מפוצלת עם עצירות וכו')
